# Kit

An expressive, modular AI familiar.

Kit is a domed animated eye with voice I/O and a PC-backed AI, starting as a USB-powered desktop peripheral and eventually supporting interchangeable bodies, battery power, and docking.

## Goals

- Expressive animated eyeball and swappable character skins
- Microphone, speaker, and optional AI backend
- PC telemetry, notifications, and automation interfaces
- Modular mechanical and electrical mounting interface
- Future battery-powered orb, charging dock, and roaming bodies

## Status

**Planning / hardware prototyping.** No hardware selection or optical design has been finalized.
